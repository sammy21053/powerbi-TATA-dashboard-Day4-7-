# powerbi-TATA-dashboard-Day4-7-


## 📌 Project Overview
This dashboard is part of my **7-Day Power BI Dashboard Challenge**.  
Day 4 focuses on building a **multi-page, interactive analytical dashboard** that allows users to explore Tata Group data across companies, stock prices, categories, leadership, and awards.

The goal was to move beyond static reporting and design a dashboard that supports **data exploration and comparison**.

---

## 🎯 Problem Statement
Large conglomerates like Tata operate across multiple industries and entities.  
Raw datasets make it difficult to:
- Compare companies at a glance
- Navigate between detailed tables and visual summaries
- Understand structure across categories, models, and divisions

This dashboard addresses those challenges through structured visuals and intuitive navigation.

---

## 📊 Key KPIs & Insights
- NSE & BSE Prices with percentage change
- Market Capitalization by company
- Average stock prices (NSE & BSE)
- Company categorization and model hierarchy
- Leadership and awards overview

---

## ⚙️ Tools & Technologies Used
- Power BI Desktop
- Power Query (data cleaning & transformation)
- DAX (basic calculated measures)
- Interactive visuals, slicers, and buttons

---

## 🧠 What I Learned
- Designing multi-page dashboards with navigation buttons
- Handling large tables without compromising readability
- Structuring dashboards for decision-making, not just visuals
- Balancing aesthetics with analytical clarity
